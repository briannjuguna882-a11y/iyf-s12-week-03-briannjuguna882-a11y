# IYF Season 12 — Week 3

## About This Project

This repository documents my Week 3 learning journey in the IYF Weekend Academy. I practised terminal commands, PowerShell automation, Git, and GitHub workflows.

- Terminal navigation and file management using PowerShell.
- Automated project setup using a PowerShell script.
- Git commits, branches, merging, and conflict resolution.
